## DynamoPilot

Интеграция Dynamo в Pilot с набором узлов (nodes) для работы с объектами Pilot. Проект поставляется с локальным ядром Dynamo и пакетами узлов, что позволяет запускать модуль без отдельной установки Dynamo пользователем.

## О Dynamo
[**Dynamo**](https://github.com/DynamoDS/Dynamo) — это визуальный редактор сценариев, где задачи собираются не кодом, а схемой из блоков-узлов. Каждый узел выполняет действие (получить данные, отфильтровать, изменить параметр), а соединения передают результат дальше. Так вы строите цепочку шагов — от входных данных до нужного результата.

**Графическое программирование (zero-coding)** означает, что логику можно создать без написания кода: достаточно перетаскивать узлы и настраивать их параметры. Это снижает порог входа и ускоряет автоматизацию рутины. При желании пользователи могут добавлять скрипты (например, Python), но это не обязательно.

## Установка

***Для одного пользователя:*** Разархивируйте DynamoPilot.App.zip по пути C:\Users\\{ВАШ ПОЛЬЗОВАТЕЛЬ}\AppData\Local\ASCON\\{ВАША ВЕРСИЯ PILOT}\Development.

***Для загрузки на сервер:*** "СЕРВИС>Модули расширения>Создать...>Расширение" в появившемся окне выберите DynamoPilot.App.zip и нажмите открыть.

Установка не требует доступа в интернет: все компоненты входят в DynamoPilot.App.zip.

## Сторонние компоненты

Папка `lib/DynamoCoreRuntime2.16.4` содержит копию Dynamo Core 2.16.4 (Apache 2.0, Autodesk; её лицензия лежит рядом, в `License.rtf`). Часть файлов этой копии закрытая: Autodesk распространяет её по собственному лицензионному соглашению, а не по Apache 2.0.

- `ProtoGeometry.dll`, `LibG.Interface.dll` — управляемая часть геометрической библиотеки Dynamo; на `ProtoGeometry.dll` статически ссылается Dynamo Core, а `ProtoGeometry.dll` ссылается на `LibG.Interface.dll`, поэтому убирать их нельзя.
- `Analytics.NET.Core.dll`, `Analytics.NET.Google.dll`, `Analytics.Net.ADP.dll`, `AdpSDKCSharpWrapper.dll` — клиенты аналитики; на них ссылается Dynamo Core (напрямую или через `Analytics.Net.ADP.dll`), без них он не стартует.
- `UI/Fonts/Autodesk/Artifakt-*.otf` — шрифты интерфейса Dynamo. По `License.rtf` (раздел об Artifakt) это проприетарные шрифты Autodesk, и их лицензия уже, чем у остальных файлов.

Эти файлы остаются в поставке, чтобы установка не требовала интернета и отдельной установки Dynamo. Нативное ядро геометрии (`libg_*`) в поставку не входит: в поставке нет ядра ASM, поэтому на чистой установке узлы геометрии Dynamo (Point, Line и т. п.) не работают.
